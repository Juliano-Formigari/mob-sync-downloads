# Möb.Sync — Downloads oficiais

Instaladores do Möb.Sync para SketchUp 2025.

## Primeira instalação e versão estável

[Baixar a última versão estável](https://github.com/Juliano-Formigari/mob-sync-downloads/releases/latest).

Na página da versão, abra **Assets** e baixe o arquivo **.rbz**. Os arquivos **Source code** não são instaladores. O mesmo RBZ aprovado é usado para primeira instalação e atualização.

No SketchUp 2025, abra o Gerenciador de extensões e escolha **Instalar extensão**. Selecione o RBZ. Em uma instalação nova, abra **Möb.Sync → Licenças…** para ativar a licença por máquina. Ao substituir uma versão já carregada, salve seus projetos, feche todas as janelas do SketchUp e reabra.

## Atualizações

No plugin, abra **Verificar atualizações**, selecione **Estável** e consulte. Quando houver uma versão mais recente, leia as notas e clique em **Atualizar**. Siga as orientações de backup, instalação e reinício. Cadastros e licenças ficam fora do RBZ; não apague suas pastas para atualizar.

## Testes privados

As candidatas de homologação ficam no canal **Teste** dentro do plugin e exigem login de uma conta autorizada. Após entrar e consultar, use **Atualizar** ou **Baixar RBZ**. Uma candidata ainda não é uma versão estável e sua publicação não altera o instalador inicial dos clientes. Novos testes não são publicados neste repositório público.

O uso das ferramentas exige licença válida por máquina. Os pacotes não incluem cadastros nem licenças de clientes. O SHA256 permite conferir a integridade; os RBZs atuais não possuem assinatura oficial do SketchUp.

Este repositório contém somente documentação pública e pacotes de distribuição. O desenvolvimento permanece em repositório privado.

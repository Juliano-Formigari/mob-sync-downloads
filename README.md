# Mob.Sync — Downloads oficiais

Instaladores do Mob.Sync para SketchUp 2025.

## Baixar

Abra [Releases](https://github.com/Juliano-Formigari/mob-sync-downloads/releases), escolha a versao e baixe o arquivo **.rbz** em **Assets**. Os arquivos Source code nao sao instaladores.

- **Pre-release / Homologacao:** versoes para teste.
- **Latest / Estavel:** versoes aprovadas para clientes, quando disponibilizadas.

## Instalar

No SketchUp 2025: Extensoes > Gerenciador de extensoes > Instalar extensao. Selecione o RBZ e reinicie todas as instancias do SketchUp. Faca backup antes de atualizar. Nao apague as pastas de dados ou licencas.

O uso das ferramentas depende de licenca valida por maquina. Os pacotes nao contem cadastros nem licencas de clientes. SHA256 permite conferir integridade; nao e assinatura digital. Candidatos atuais ainda nao possuem assinatura SketchUp.

Este repositorio contem somente documentacao publica e pacotes de distribuicao. O desenvolvimento permanece em repositorio privado. O plugin ainda nao instala atualizacoes automaticamente.
